# Architecture decision records

An ADR records a significant decision: the context, the options considered, what was
decided and its consequences. Write one before adding a runtime dependency, a new output
format, or JavaScript to the generated page.

To add one, copy the structure of the latest ADR into `NNNN-short-title.md` with the next
number, and open it as part of the PR that implements the decision. ADRs are not edited
after acceptance; a new ADR supersedes an old one and both are updated to say so.
